📊 HR Analytics Dashboard (Excel & Power Query)

An interactive and dynamic HR Analytics Dashboard created using Microsoft Excel and Power Query. This project provides actionable insights into workforce demographics, employee attrition, department performance, and compensation metrics to support data-driven HR decisions.

Number of Employees by Manager:

Tracks workforce distribution across managers (Alice, Bob, Carol, Dan, Eva).

Department-Wise Attrition (Active vs. Inactive):

Compares active and inactive workforce across departments (Finance, HR, IT, Marketing, Sales).

Helps identify high-turnover areas within the organization.

Gender Ratio:

Average Salary by Department:

Highest average salary is in Finance (₹80,100.78) and HR (₹79,005.78).

Percentage of Employees City-Wise:

Geographic distribution across key metro cities: Bengaluru (21.60%), Delhi (21.20%), Kolkata (19.60%), Mumbai (19.60%), and Pune (18.00%).

🛠️ Tools & Technologies Used

Microsoft Excel: Data visualization, KPI card metrics, and interactive Slicers.

Power Query: Data cleaning, ETL processing, merging datasets (Employees, Departments, Performance data), and transformation.

Pivot Tables & Pivot Charts: Dynamic grouping and chart rendering.
